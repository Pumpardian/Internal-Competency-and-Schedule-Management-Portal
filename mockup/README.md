# Макет интерфейса портала (Этап 1)

прототип внешнего вида двух страниц портала на **React**:

- **Команда и навыки** - матрица компетенций в виде тепловой карты; клик по ячейке меняет уровень владения (0–5) ползунком.
- **Переговорная** - календарь дня; клик по свободному часу открывает модальное окно создания брони; пересечение по времени отклоняется с уведомлением **409 Conflict**.

Макет написан на React с функциональными компонентами и хуками. 
На этапе 3 этот прототип переделаем в клиентку, а заглушки данных заменим вызовами.
