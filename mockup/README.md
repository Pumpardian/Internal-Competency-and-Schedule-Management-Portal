# Макет интерфейса портала (Этап 1)

Прототип внешнего вида двух страниц портала на **TypeScript + React** (сборка через **Vite**):

- **Команда и навыки** — матрица компетенций в виде тепловой карты; клик по ячейке меняет уровень владения (0–5) ползунком.
- **Переговорная** — календарь дня; клик по свободному часу открывает модальное окно создания брони; пересечение по времени отклоняется с уведомлением **409 Conflict**.

Макет написан на React с функциональными компонентами и хуками, весь код типизирован (TypeScript, строгий режим).
На этапе 3 этот прототип переделаем в клиентку, а заглушки данных заменим вызовами API.

## Запуск

```bash
npm install
npm run build
npm run dev       # дев-сервер Vite (http://localhost:5173)
```

## Структура

```
mockup/
├─ index.html              # точка входа Vite
├─ package.json
├─ tsconfig*.json          # конфиги TypeScript
├─ vite.config.ts
└─ src/
   ├─ main.tsx             # рендер приложения
   ├─ App.tsx              # корневой компонент, состояние и роутинг между страницами
   ├─ types.ts             # доменные типы (Employee, Skill, Booking, …)
   ├─ data.ts              # тестовые данные и константы
   ├─ utils.ts             # форматирование времени, проверка пересечений
   ├─ styles.css
   ├─ hooks/
   │  └─ useToasts.ts      # самоудаляющиеся уведомления
   └─ components/
      ├─ Header.tsx
      ├─ Toasts.tsx
      ├─ TeamPage.tsx
      ├─ LevelPopover.tsx
      ├─ RoomPage.tsx
      └─ BookingModal.tsx
```
